嵌入式培训工具链配置测试，不需要连接开发板，不需要配置烧录器或调试器

## 1. 克隆仓库
选择一个路径中没有中文和空格的位置，例如：
C:\Workspace

在终端中进入该目录：
```
cd <你的工作目录>
```
然后克隆本仓库：
```
git clone <本仓库地址>
```
进入仓库：
```
cd <仓库文件夹名称>
```
用vscode打开工程

## 2. 配置并编译工程

运行：

```
cmake --preset Debug
cmake --build --preset Debug
```
或者按vscode内的“生成”或“build”按键

如果构建成功，你应该能够看到类似以下的信息：

[build] [100%] Linking C ...
[build] [28/28] Linking C ...

同时也会显示“生成完毕”等信息，在构建目录中应该能够找到生成的：*.elf文件。
